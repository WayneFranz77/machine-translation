# Machine Translation

English to Spanish machine translation using a Seq2Seq Encoder-Decoder architecture built with TensorFlow and Keras.

## Features

- Text preprocessing
- One-hot encoding
- Encoder-Decoder LSTM
- Teacher forcing
- Model training
- Translation inference

## Tech Stack

- Python
- TensorFlow
- Keras
- NumPy

## Project Structure

data/        Dataset files
src/         Source code
models/      Saved models
tests/       Test scripts
